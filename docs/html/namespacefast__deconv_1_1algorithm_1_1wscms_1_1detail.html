◆ psf_subtract_kernel()

void fast_deconv::algorithm::wscms::detail::psf_subtract_kernel ( float *  residual,
const float *  psf,
overlap_region  ovr,
float  factor 
)

Subtract PSF scaled by factor from residual on the specified overlap region.

Performs residual(ovr.a) -= factor * psf(ovr.b) element-wise over the overlap region defined by ovr. Uses a grid-stride loop so that any launch configuration covers the full region.

Parameters
[in,out]residualResidual image, row-major with leading dimension ovr.lda.
[in]psfPSF image, row-major with leading dimension ovr.ldb.
[in]ovrOverlap region descriptor giving the origin and extent of the sub-windows in both residual (a) and psf (b).
[in]factorLoop gain (scale factor applied to the PSF before subtraction).
